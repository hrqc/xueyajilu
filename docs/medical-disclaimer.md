# 医疗免责声明

本应用不能替代医生诊断，如有不适请及时就医。

BPHealth 仅用于记录血压、观察趋势和提供一般健康管理参考。分类规则不构成诊断，饮食建议不构成处方或治疗方案。不得依据本应用自行停药、改药或延误就医；出现胸痛、呼吸困难、意识改变、单侧无力、严重头痛或其他急症信号时，应立即联系当地急救服务。

儿童、孕期、老年人、肾病、糖尿病、心脏病及正在用药的人群，应将记录交给医生进行个体化评估。

隐私说明：血压记录、个人资料和设置默认保存在设备本地；HealthKit、通知和生物识别均需用户授权；当前版本不会自动启用 iCloud 或在线 AI。用户可以在应用内导出或删除记录，也可以在系统设置中撤销相关权限。
